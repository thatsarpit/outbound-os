# Outbound OS 0.3.0

This release combines the inbox/mobile repairs, dependency upgrades, direct Meta
transport, source-neutral connector imports and public website refresh.

## Upgrade

Read [the Meta-only upgrade guide](../meta-only-upgrade.md) before restarting an
existing installation. Back up the database and preserve its existing encryption
keys privately. The migration removes obsolete provider credential columns.
Rollback needs the old database and compatible image together; replacing the image
alone is insufficient. Keep login settings unchanged unless doing a separately
planned authentication migration.

Direct Meta account IDs, current encrypted credentials and conversation history
are retained. Retired-provider accounts are disabled. Invalid default template
labels are cleared. Imports never enqueue outreach, and website service enquiries
are opt-in and saved paused without marketing consent.

## Website design and SEO

The homepage pairs a desktop inbox with a readable phone illustration. These are
labelled fictional product illustrations; secondary product screenshots use sample
data. The demo remains the place to interact with the actual dashboard.

The site uses static HTML, local fonts, SVG icons, CSS transitions and finite
entrance motion. A visible pause control stops explanatory animation loops;
reduced-motion preferences also disable animation. No new animation dependency,
canvas background, external font request or video player is needed for this pass.

Free options reviewed: [Motion's bundle guidance](https://motion.dev/docs/react-reduce-bundle-size),
[Magic UI examples](https://magicui.design/docs/components/animated-beam) and its
[MIT licence](https://github.com/magicuidesign/magicui/blob/main/LICENSE.md), and
[GSAP's free offering](https://gsap.com/pricing/). The shipped illustrations are
original HTML/CSS rather than copied library components.

Existing OpenSEO/DataForSEO research informs the buyer page `/whatsapp-crm`,
integration page `/integrations/whatsapp-cloud-api`, how-to guide
`/docs/whatsapp-cloud-api` and source-neutral `/integrations/webhooks`. Sample
market estimates are not traffic forecasts. There is no additional paid keyword
research or tracking job in this release.

`npm run check:export --prefix website` validates each exported page's unique
title/description, canonical, social image, structured data, internal links and
image files, plus exact sitemap membership and retired-route redirects.

## Acceptance boundaries

Automated verification covers isolated API/database flows, migration recreation,
MCP transport and static builds. Integrations → AI agents now provides public
connection details, read-only health/discovery checks and client setup instructions,
without exposing backend credentials or claiming an agent is authorized. It does not prove physical iPhone Notification
Center delivery or visual acceptance on every device. iPhone Web Push still needs
Home Screen installation on a supported iOS version and device permission.

Global queue-control tools, historical email classification repairs and the live
Clerk migration remain separately tracked. This release does not silently change
an existing login provider or mark those items complete.
