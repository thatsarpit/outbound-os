## Included and released

- Dashboard workflows, personal integration controls and account/device settings
  from #53; retained-email review and verified attachment downloads from #57.
- Production Clerk owner migration, Google identity linking and signed live
  updates, including the EventSource authorization fix in #63.
- API/MCP dependency security updates in #65. The GitHub audit on 25 October
  found no open Dependabot alerts.

The recorded rollout deployed matching API/MCP images to AWS and the dashboard
to Cloudflare Pages. Existing authentication/OAuth state and device registration
were preserved, with private rollback backups retained. Owned pilot email body
and attachment integrity checks passed. Customer test messages and campaigns
were not part of validation.

Required validation passed: 355 unit/fixture tests, four existing TODOs, 131 API
integration tests, 22 MCP tests, dashboard checks/builds, website export, Docker
boot and CodeQL. A new checkout should rerun the applicable checks; these counts
describe the released baseline.
