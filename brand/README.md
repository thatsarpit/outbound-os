# Outbound OS brand assets

| File | Use |
|---|---|
| `outbound-os-mark.svg` | The mark on its own: app icons, avatars, favicons |
| `outbound-os-lockup-dark.svg` | Mark and wordmark for light backgrounds |
| `outbound-os-lockup-light.svg` | Mark and wordmark for dark backgrounds |

The mark is a customer record (the rounded square) with the next action
leaving it (the arrow). It is one shape, so it also works in a single colour:
use `currentColor` from `website/components/brand-mark.tsx`.

## Colours

| Token | Hex | Use |
|---|---|---|
| Ink | `#17171C` | Text, primary buttons |
| Night | `#0B0D10` | Dark surfaces, the mark's tile |
| Paper | `#FAFAFB` | Page background |
| Green | `#22C55E` | The brand accent: fills, light, the mark |
| Deep green | `#047857` | Green text on light backgrounds (5:1 contrast) |

Other products' logos on the website are their owners' trademarks, shown only
to say what Outbound OS connects to.
